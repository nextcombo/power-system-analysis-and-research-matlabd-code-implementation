# Power System Analysis and Research (Matlabd Code Implementation)

Power system analysis and research (Matlab code implementation)  
Consider a three-phase single return transmission system, which consists of all three phases bundled conductors. The subconductors of the bundle are twisted ACSR conductors. Develop an interactive user interface to collect the following parameters for the transmission system from the user:  
System type - Symmetric or asymmetric spacing (transposed)  
Phase conductor spacing  
Number of subconductors per bundle  
Subconductor spacing between bundles  
Number of windings in each subconductor  
Diameter of each wire  
Length of the line (km)  
Line model (short/standard pi/long)  
Resistance per kilometer of the line  
Alternating current (Ac)  
Nominal system voltage  
Receiver load (MW).  
Receiver load power factor.  
Output results:  
Per unit length of each phase inductance, H/km  
Per unit length of each phase capacitance, F/km.  
Impedance of the line in ohms per unit length.  
Impedance of the line in ohms per unit length.  
Charging current drawn from the sending end substation.  
Calculate ABCD parameters of the line.  
If the receiver voltage remains at the nominal system voltage, calculate the sending end voltage in kV.  
Calculate the sending end current in A.  
Calculate voltage regulation percentage.  
Calculate power loss in the line in MW.  
Calculate transmission efficiency.  
Draw sending end circle diagram.  
Draw receiving end circle diagram.  
Comment on the compensation requirements at the receiving end to keep voltage at the nominal value (only applicable for short lines).  
Calculate the amount of compensation required in MVar. (Only applicable for short lines).  
The program is written in MATLAB R2021a.  
Uploaded example input files and calculation parameters for this specific overhead cable will be displayed in the output file. Check power_circles.png to get the short line model diagram and power_circles (three_models) .png to compare with all three line models.
